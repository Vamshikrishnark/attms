# ATTMS - Automated Test Tool Management System

One test case across the whole chain: web pages, APIs, databases, Kafka, files, Windows and SAP GUI
desktop apps, mobile apps and vehicle ECUs (CAN, UDS, DoIP). Every step keeps its evidence. It runs
on your own machines, offline, with a local AI.

Product page: **https://vamshikrishnark.github.io/attms/** · Demo video: see the
[latest release](../../releases/latest).

## Download

The Windows package is attached to each [release](../../releases): `ATTMS-<version>-build<N>.zip`
with a `.sha256` next to it. Unzip, double-click `ATTMS.bat`, answer three questions. The README
inside the zip explains the rest (other computers, agents, updates).

Requirements: Windows 10/11 64-bit for the hub and the recorder; agents also run on Linux and
Docker. Nothing needs the internet.
